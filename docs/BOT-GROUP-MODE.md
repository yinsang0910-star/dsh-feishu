# 群聊不用 @ 也能用（2026-10-31 改造）

## 一句话

配置项 `group_require_mention: false`（**默认就是 false**），群里直接说话就行，
不用 @「G2 Agent」；想恢复成「必须 @」就发一句 `/要@`。

## 前提（已经满足，不用再动）

飞书要能把**群里没人 @ 的普通消息**推给机器人，应用必须有
「获取群组中所有消息」这类权限（`im:message.group_msg`）。如果只有
`im:message.group_at_msg`，事件根本不会来，改代码也没用。

判断方法很简单——看日志里有没有不带 @ 的群消息：

```
INFO recv type=image chat=oc_7c2899... chat_type=group sender=ou_aee4...
INFO recv type=text  chat=oc_7c2899... chat_type=group sender=ou_aee4...
```

有，就说明权限到位（这台机器 2026-10-31 的日志里，没 @ 的图片消息一直在推过来）。

## 行为矩阵

| 谁 / 在哪 | 发什么 | 现在（免 @） | `/要@` 之后 |
|---|---|---|---|
| 白名单成员 · 群 | 文字 | 直接当任务处理 | 必须 @ 才处理 |
| 白名单成员 · 群 | 图片 / 文件 | **直接处理**（不再「先收着」） | 先收着，等他 @ 一句再挂上去（15 分钟有效） |
| 白名单成员 · 群 | 表情包 / 合并转发等 | 静默忽略，不解释 | 同左 |
| 白名单外的人 · 群 | 任何消息 | **完全静默**（一条都不发） | 同左 |
| 任何人 · 私聊 | 文字 / 图片 / 文件 | 照常处理 | 照常处理 |

白名单外的静默是这次特意加的：以前会在群里回「你在白名单外，找管理员加一下」，
免 @ 之后群里每句闲聊都会触发一次，等于刷屏。现在只有私聊才解释。

## 开关

```
/免@        # 群里直接说话就行（默认）
/要@        # 群里必须 @ 才响应
/mention    # 不带参数 = 切换当前状态
/状态       # 会显示「群里：不用 @ 也响应（/要@ /免@ 切换）」
```

切换会写回 `/opt/feishu-bot/config.json`，重启不丢。

## 为什么还要留着 `/要@`

群里人一多、或者聊到一半在讨论别的事，免 @ 会让它每条都接。这时候 `/要@` 一句话
就把模式收回去，等需要它的时候再 @。两种模式共用同一套会话和记忆，切换不丢上下文。

## 实测（2026-10-31 20:55，真图 + 真 dsh，只把发送换成本地记录）

| 场景 | 结果 |
|---|---|
| 群里说「回答两个字：收到」，没 @ | 8 秒建卡 → ✅ 完成，答「收到」 |
| 群里直接发那张化学试卷图，没 @ | 13 秒 → 「有机化学试卷照片，(a) 酸催化水合，(b)(c)(d) 加 HBr…要批改还是给标答？」 |
| 白名单外的人说「你们在聊什么」 | 0 条外发 |
| 群里发表情包（sticker） | 0 条外发 |
| 带 @ 说话 | 照常（@ 依然是有效触发方式） |
